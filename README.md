# Simple-Calculator by using C++ -
A Simple Calculator application using C++

## Features
- Addition (+)
- Substraction(-)
- Multiplication(*)
- Division(/)

## Technologies used 
- C++
- iostream
- switch Statement

## How to Run
- Download the Calculatorproject.cpp file
- compile the program using a C++ compiler.
- Run the Program.

## Sample Output
Enter the first number: 10
Enter the operator(+,-,*,/): +
Enter the second number: 20 
Result = 30
